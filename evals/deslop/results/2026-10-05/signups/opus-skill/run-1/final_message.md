I cleaned up `build_attendees` in `signups.py`. The branch had re-implemented things the file already has, so the code now uses the existing `normalize_email`, `MAX_NAME_LEN` and `WAITLIST_TAG` in place of copies and hard-coded values. Duplicates, blank emails, staff rows, the name length limit and the waitlist all came out as expected.
