## Caveats
- One 63-line fixture, 3 runs per cell. A 100% score for Sonnet may mean the task is too easy to show a difference.
- The slop in the fixture overlaps the examples named in `skills/deslop/SKILL.md` (type escapes, change-describing comments, single-use wrappers), so part of the Haiku gain is the skill recognizing its own examples. A fixture with slop the skill doesn't name is still to do.
- Behavior check covers valid input only. Removing the broad except makes `restock_plan` raise on bad input; the reference does this too.
- Opus untested. Runs were graded after a review found the first grader gameable; the first grader's scores (Haiku 74% -> 95%) moved to 74% -> 91% after hardening. Note the run harness left `check.py` inside the repo for these runs; the hardened grader ignores that copy.
